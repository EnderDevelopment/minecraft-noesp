# NoESP

NoESP is a Minecraft plugin designed to enhance gameplay by hiding everything below the y=0 level for players who are above y=16. This plugin prevents players from using freecam to easily locate hidden bases, encouraging them to dig down to the deepslate level and mine to the sides. It creates a more challenging and immersive mining experience.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server.

## Use

1. Start your Minecraft server with the plugin installed.
2. Players will automatically experience the NoESP effect when they move above y=16.
3. The plugin will hide everything below y=0 for players above y=16.
4. When players move below or to y=16, the hidden area will be shown again within a 4-chunk radius.
